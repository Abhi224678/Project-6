
# Project 6: Version Control Infrastructure

## Objective
I used Git and GitHub to manage and track changes to Terraform infrastructure code using version control.

## Tasks Completed

### 1. Push Code to GitHub
1. Created a separate project repository.
2. Initialized Git in the project directory.
3. Added the Terraform configuration file.
4. Committed the initial code.
5. Created a GitHub repository.
6. Pushed the Terraform code to GitHub.

### 2. Raise a Pull Request
1. Created a feature branch named `feature/project6-update`.
2. Updated the Terraform configuration file.
3. Committed the changes.
4. Pushed the feature branch to GitHub.
5. Created a Pull Request targeting the `main` branch.

## Tools Used
- Git
- GitHub
- Terraform
